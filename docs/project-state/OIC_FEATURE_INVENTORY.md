## Implementation limits (not OIC-5 GO gaps)

- The release acceptance proves the named A–P cases and bounded strategy/backtracking scenarios. It does not claim every possible plan, controller action, or search state is operationally selected in a single run.
- Same-provider/model LIGHT, ADVANCED, and MAX behavior was measured against the accepted task/profile cases. The different budgets and outcomes are accepted semantics; this is not a universal answer-quality ranking.
- Memory fusion, temporality, derived consolidation, lifecycle behavior, sensitivity handling, and the named seven-row isolation matrix have the deterministic coverage shown in the acceptance ledger. The system does not claim unbounded autonomous learning or universal retrieval precision.
- Cross-source evidence relations remain heuristic. Explicit in-memory dependency references now emit and affect verification, but persisted runtime sources do not populate these references. Hypothesis support and claim evidence mapping remain lexical. Retrieval quality, verifier quality, and uncertainty are not calibrated.
- Workbench service and authenticated-browser acceptance compare baseline and OIC against the known deterministic local fixture. Trace Inspector opened and inspected a generated trace; the acceptance does not represent external-provider quality or latency.
- Authenticated Console acceptance exercised Profiles, Memory, Knowledge, Workbench, Trace Inspector, and lifecycle controls in EN/LTR and AR/RTL, desktop and narrow layouts. The memory UI cannot list SESSION records through admin routes; runtime session memory stays scoped to the exact authenticated actor and runtime session.
- Streaming remains buffered for all intelligence requests. Repeated p50/p95 local fixture measurements exist for four representative scenarios; external-provider behavior and broad observability remain unmeasured.
- The local database schema and migration state are validated. No production deployment or broad external-provider benchmark is claimed by this local OIC-5 closeout.
