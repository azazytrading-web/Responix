## State definitions applied

- **LIVE**: canonical source returned the displayed value/state.
- **NO_DATA_YET**: source works, but no relevant execution/event rows exist.
- **UNMEASURED**: capability exists, but no approved measurement/method/value is bound.
- **UNAVAILABLE**: an expected read or source field is inaccessible/absent; it is not a measured zero.
- **ERROR**: reserved for an actual failed read/invalid source state; no error is claimed from missing telemetry alone.
- **NOT_IMPLEMENTED**: not used for planned metric definitions whose capability exists but measurement adapter/method is pending; those are marked UNMEASURED or UNAVAILABLE as applicable.
