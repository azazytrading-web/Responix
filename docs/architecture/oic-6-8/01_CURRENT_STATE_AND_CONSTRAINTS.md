**Existing infrastructure:** OIC uses PostgreSQL/Prisma transactions and uniqueness constraints, API services/controllers, runtime request identity and resolver, bounded trace/audit views, and BFF machine credentials. Targeted source search found no OIC Redis/BullMQ worker or durable queue abstraction. The prior OIC-5 acceptance ledger is a test/acceptance artifact, not a production accounting ledger. The existing upstream pricing evidence is nullable and observed, not authoritative billed cost. Streaming idempotency is explicitly unsupported in current runtime; OIC-6 cannot claim retry safety there without a new protocol. No current OIC-6 usage/quota tables, OIC-7 evaluation tables, or OIC-8 proposal tables were found.

**API source map:** `foundation.controller.ts` owns `/admin/applications`, tenant/principal grants and `/admin/audit`; `provider-control.controller.ts` owns `/admin/providers` and provider connections; `model-fabric.controller.ts` owns catalog, model lineage and runtime-binding commands; `intelligence.controller.ts` owns `/admin/intelligence/{profiles,executions,memory,knowledge}`; `runtime.controller.ts` owns `/runtime/{invocations,stream}`; `openai-compatibility.controller.ts` owns `/v1/{models,chat/completions,responses}`. The Console uses server BFF routes `/api/console` and `/api/action` rather than browser-to-API machine credentials. These are current surfaces; proposed OIC-6/7/8 APIs are new and are not implemented.

**Frozen UI:** `apps/oic-console/app/components/interface/` and `components/instruments/` are the OIC-owned canonical libraries. New pages consume these; no X1 redesign, demo values in production, or local component forks. X1 closeout is `docs/project-state/OIC_X1_FINAL_CLOSEOUT.md`.
