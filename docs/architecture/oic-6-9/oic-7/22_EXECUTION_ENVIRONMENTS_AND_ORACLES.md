# OIC-7 v1.0 — execution environments and objective oracles

Environment adapters are versioned, sandboxed OIC evaluator plugins. They receive a scoped case manifest and a target invocation capability, never unrestricted DB/credential access. Each produces an artifact manifest, attempt trace references, resource use and oracle outcome. The adapter's image/fixture digest, tool allowlist, network policy, time/resource limits and teardown proof are part of the target/test fingerprint. Evaluator-owned oracles run outside candidate writable space. Production provider calls still pass OIC-6 admission.

| Domain | Environment and oracle contract | Gaming defense / availability |
|---|---|---|
| Coding | Pinned repository commit and task patch; isolated ephemeral FS/container; public tests plus sealed evaluator tests, static/security checks and human review where needed. Objective oracle validates tests, permitted diff, regression and policy. | Candidate cannot edit evaluator tests, harness, scoring files or network policy; no unbounded internet; detect deleted tests, hardcoded outputs and stub-only pass. Sandbox escape halts case as `INVALID`, never score zero. |
| Agentic coding / software engineering | Multi-step repository issue with bounded tools, commit/diff and replayable workspace state. Score task completion, regression, quality, security and resource use separately. | Sealed tests and fixture hashes outside workspace; changed tests count as manipulation. Partial task success is typed, not simple pass. |
| Terminal/computer operation | Scripted virtual environment snapshot with allowlisted commands/files and deterministic reset; state assertions and prohibited-action checks. | Network/filesystem sandbox, transcript allowlist, time cap; no host shell. |
| Tool/function calling | Versioned JSON schemas, mock side-effect ledger, permission rules and expected call/state transitions. | Schema pass alone is insufficient; verify correct target, argument, order and no forbidden side effect. |
| Retrieval/RAG | Frozen corpus/index revision, query, relevance labels and cited evidence; metrics separate retrieval recall/precision, citation support and final answer fidelity. | Answer-only grading cannot claim retrieval quality; leakage from reference text or wrong corpus invalidates. |
| Memory | Controlled memory state and temporal facts with consent/sensitivity rules; test lookup, update, non-use and deletion boundaries. | Stored salience/confidence is not utility; privacy violation is critical gate. |
| Reasoning/math/data analysis | Reference or executable oracle where available; numeric tolerance/unit, proof/checkable steps if public and lawful. | Judge-only correctness marked subjective; no hidden chain-of-thought required or retained. |
| Multilingual/Arabic | Native-authored and reviewed cases with dialect/script/RTL metadata, parallel semantic cases where valid and language-specific rubrics. | Machine translation alone cannot certify parity; compare within language/slice; font/UI direction not inferred from text score. |
| Communication/customer service | Bounded stateful simulator with user goal, product truth, policy and escalation options; objective policy compliance plus blinded human/judge helpfulness. | Simulator must not reward verbosity, unsafe persuasion or fabricated promises. |
| Sales/negotiation | Versioned personas/needs/budget/product catalog/offer authority and deal-state simulator; outcome is one dimension beside customer fit, truthfulness, consent, pressure, margin/discount policy and escalation. | Unauthorized discount or hallucinated feature is hard failure even if simulated deal closes; no single conversion score. |

**Simulation validity:** User simulators are not ground truth. Pin simulator model/config/seed, persona and state machine. Use multiple simulators, human calibration and adversarial scripts; report simulator-specific effects. A target cannot access simulator hidden state or modify it. Multi-turn trajectory logs contain only permitted conversation content and tool events; hidden reasoning is never required. Non-replayable external state yields `BEST_EFFORT` provenance, not exact reproducibility. Negative effects (policy abuse, unsafe action) are separate critical metrics, not averaged away by success.

**Objective-oracle priority:** deterministic state assertion > executable reference/test > independent human rubric > calibrated model judge > unsupported. A model judge can grade style or semantics but cannot override a deterministic security failure. Each oracle has revision, confidence/coverage, failure state and false-positive calibration. Oracle crash/missing artifact yields `NO_MEASUREMENT`; evaluation retries within budget/fence. Partial attempts retain evidence and are excluded or counted as failure according to preregistered suite policy, never chosen after results.

**Safety and operations:** default deny egress, tool allowlists, secret-free fixtures, CPU/memory/time/file/network quotas, per-case teardown, malware/SSRF defense, artifact encryption and retention. Runners have least privilege and no production credentials. Provider callbacks and result artifacts are verified by digest; evaluator containers cannot write holdout source. Capability to evaluate real product data requires explicit tenant permission and isolation; Responix/Portal DBs remain inaccessible. Sandbox availability and oracle validity are monitored. Initial implementation uses deterministic local fixtures before paid providers or complex simulations.
