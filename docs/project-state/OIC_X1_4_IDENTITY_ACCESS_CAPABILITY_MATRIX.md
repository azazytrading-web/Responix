## Request and security path

The browser posts named actions to same-origin `/api/action`. That route keeps `sameOrigin(request)` and `hasConsoleSession()` guards, validates action-specific values and UUIDs, uses the existing control-plane machine credential, and marks requests `no-store`. The API continues to apply its existing authenticated-principal, scope, application/tenant boundary and audit rules. X1.4 does not weaken these protections.

The Console snapshot keeps credential fields explicitly selected. X1.4 adds only safe external-reference `revokedAt` metadata needed to represent the existing lifecycle. No schema migration or database change is required.
