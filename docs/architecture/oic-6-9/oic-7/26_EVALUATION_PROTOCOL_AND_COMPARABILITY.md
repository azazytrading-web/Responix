# OIC-7 final evaluation protocol and comparable-result algorithm

This is the **normative OIC-7 protocol**. A measurement can exist without being decision-eligible. Every result is tied to a published immutable `EvaluationProtocolManifest` (EPM), not merely a run name. OIC Evaluation Fabric owns the protocol; domain packs supply typed plugins but cannot redefine the core state, evidence, scope or comparability rules.

## Target class and immutable manifest

`targetClass` is exactly one of `BASE_MODEL`, `MODEL_BINDING`, `MODEL_WITH_PROFILE`, `MODEL_WITH_OIC_RUNTIME`, `AGENT_SYSTEM`, `TOOL_ENABLED_SYSTEM`, `RETRIEVAL_AUGMENTED_SYSTEM`. A base-model target invokes provider/model without OIC profile/agent orchestration; an agent-system target includes loop, planner, tools and scaffold. They cannot share a ranked family. A result must display its target class and the complete resolved target tuple. An optional feature may be declared `NOT_APPLICABLE`; it cannot be silently omitted.

EPM required immutable fields: `protocolVersion`, `targetClass`, application/tenant scope, model edition/revision/variant/binding and provider/upstream IDs or exact external target identity, profile revision, runtime engine version, **harness/scaffold revision and digest** (agent loop, parser, planning, context assembly, tool routing and retry), tool/retrieval/context policy revisions, benchmark pack/release and suite IDs/digests, ordered dataset/case revision IDs and content hashes, environment/container/dependency/network policy digest, action/observation schema, oracle revision, metric/judge revisions, case weights/slices, stochastic parameters (temperature/top-p/seed/support status), planned repetitions, physical retry policy, sampling/stopping/aggregation/statistics revisions, OIC-6 budget/policy revision and cost coverage rule, artifact/redaction policy and result verification tier. Optional fields are represented by explicit `NONE|UNSUPPORTED|UNKNOWN` values. EPM digest is SHA-256 of RFC 8785 canonical JSON after domain-specific normalized timestamps/decimal strings and sorted unordered ID sets; ordered case/trial schedules remain ordered. A published EPM row is immutable; changed target, harness, pack, suite, oracle, judge, metric or retry rule creates another manifest ID/digest. Run and every case execution FK the EPM.

`Run` is one target plus one EPM/campaign on a fixed case plan. `CaseExecution` is the logical `(runId, caseRevisionId, repetitionOrdinal)` and owns one reportable outcome. `Attempt` is a physical dispatch/retry with independent OIC-6 admission and resource evidence. An infrastructure retry may salvage a failed logical execution according to preregistered policy but **does not add a stochastic repetition**. A stochastic repetition is scheduled before outcomes, has distinct ordinal/seed and counts toward reliability. Unknown physical attempt outcome keeps logical execution inconclusive until reconciled; it cannot be quietly dropped. Capability = estimated success under specified conditions; reliability = across-trial completion/failure/variance with denominator and conditions.

## Formal comparability

The comparison service returns enum `DIRECTLY_COMPARABLE`, `MATCHED_SUBSET_COMPARABLE`, `NORMALIZED_COMPARISON_AVAILABLE`, `DESCRIPTIVE_ONLY`, `NOT_COMPARABLE`, plus machine-readable `reasonCodes[]`, common-case IDs, excluded-case IDs, coverage, method revision and decisionEligible boolean. It executes these rules in order:

1. Reject missing/invalid scope rights, revoked/compromised release, artifact provenance, unknown target class, or incompatible target classes: `NOT_COMPARABLE` (`SCOPE_DENIED`, `RELEASE_INVALID`, `EVIDENCE_INVALID`, `TARGET_CLASS_MISMATCH`). Base model vs agent system never auto-normalizes.
2. Compare EPM fields. A changed harness/scaffold, environment, action/observation schema, oracle, judge, metric, retry/repetition/stopping or sampling policy is `DESCRIPTIVE_ONLY` unless a published bridge study specifically proves a compatible normalized mapping for that field and cohort. A changed benchmark release/case set is never direct. Provider/model/profile/binding changes are permitted only as the **declared treatment**; unintended simultaneous changes yield `TREATMENT_CONFOUNDED` and descriptive only.
3. If all protocol conditions and exact case/trial schedule match, return `DIRECTLY_COMPARABLE`; if only case membership differs but a preregistered common subset retains required slice coverage/minimum effective n, return `MATCHED_SUBSET_COMPARABLE` with subset-only estimates. It is not a full-suite result. If a published bridge/calibration revision maps differing releases/methods and uncertainty propagates, return `NORMALIZED_COMPARISON_AVAILABLE`; show both raw and normalized results and bridge uncertainty. Without valid bridge return `DESCRIPTIVE_ONLY` or `NOT_COMPARABLE` if no meaningful common construct.
4. `decisionEligible=true` only for direct comparison, or a gate policy published *before* the runs expressly allowing a matched subset/validated normalization, with adequate n, critical slices, complete evidence, cost/OIU coverage and fresh holdout. Exploratory analyses and imports are always false for production promotion. `MEASUREMENT_AVAILABLE` never implies `DECISION_ELIGIBLE`.

Reason vocabulary includes `CASE_SET_MISMATCH`, `RELEASE_MISMATCH`, `HARNESS_REVISION_MISMATCH`, `ENVIRONMENT_MISMATCH`, `ORACLE_REVISION_MISMATCH`, `JUDGE_REVISION_MISMATCH`, `METRIC_REVISION_MISMATCH`, `STOCHASTIC_POLICY_MISMATCH`, `RETRY_POLICY_MISMATCH`, `SAMPLING_POLICY_MISMATCH`, `INSUFFICIENT_COMMON_CASES`, `CRITICAL_SLICE_MISSING`, `BRIDGE_UNVALIDATED`, `MISSING_ATTEMPT`, `COST_UNKNOWN`, `HOLDOUT_EXPOSED`, `EXTERNAL_UNVERIFIED`. The report preserves all codes, not just first failure. A leaderboard filters to a single target class, release, EPM-comparability family, metric/method and evidence tier; no universal leaderboard. No unqualified winner for descriptive/incomparable results.

## Release, verification and evidence completeness

Benchmark release states `DRAFT→VALIDATED→PUBLISHED→DEPRECATED→RETIRED` or `INVALIDATED` from any published state. Publication freezes case manifest, environment, pack/plugin and rights. Deprecation stops new default runs but retains history; retirement blocks new runs; invalidation blocks decision use, marks impacted reports/verdicts invalid and creates incident, never deletes evidence. Regrading creates new report/metric revision lineage over retained raw artifacts, with original report preserved; if artifact unavailable, status `UNGRADABLE`. Live/rotating releases have `generationWindow`, private eligibility interval, publish time, minimum unseen period, retirement time and exposure policy. A new release never inherits old scores automatically.

Verification tier is `OIC_EXECUTED_VERIFIED` (OIC controls attempt, artifact and oracle), `OIC_EXECUTED_PARTIAL` (missing receipt/artifact), `EXTERNAL_ATTESTED` (signed source/adapter verified), `EXTERNAL_IMPORTED` (mapped but not independently verified), or `SELF_REPORTED`. Only first tier can support default production promotion; an explicit future gate policy may permit attested evidence only after independent validation. A result is complete only if EPM/release/target/harness, planned case/trial denominator, every attempt terminal or marked missing, artifact digest, oracle/judge revision, metric availability, scope, source trace, OIC-6 cost/OIU status, timestamps and statistical method are present. Incomplete evidence is displayed but not decision-eligible. Imported evidence never masquerades as OIC execution.

`EvaluationPassport` is the bounded signed/digested read model over target class/identity, EPM/release, verification tier, coverage, metrics/intervals, reliability, latency decomposition (queue, environment, target, tool, judge), target execution cost/OIU versus total evaluation infrastructure cost, comparability, rights/visibility and timestamps. Passport rebuilds from immutable evidence; it is not an editable score. Cost-per-qualified-success uses all physical target attempts plus declared tool cost divided by preregistered qualified successes, with provider cost evidence status; total evaluation expense additionally includes judge, harness and environment. Unknown numerator or incomplete denominator yields unavailable, never zero/free.
