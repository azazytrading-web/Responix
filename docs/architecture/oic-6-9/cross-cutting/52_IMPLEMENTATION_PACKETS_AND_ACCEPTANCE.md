# OIC-6–9 bounded implementation packets and acceptance

**Sequence rule:** OIC-6 admits/accounts before paid OIC-7 evaluation; OIC-7 validates before OIC-8 production promotion; OIC-9 certifies release but does not replace domain gates. The architecture and packet sequence are owner-approved and locked; packet implementation remains not started until explicitly entered. `Schema` means a future additive migration owned by that packet, **not** a migration created in this architecture pass. Every packet requires scoped security review, docs, observability, safe rollback and owner checkpoint. Hard stop after a failed gate; do not advance automatically.

**Acceptance matrices:** OIC-6 requires exact postings/projection, no duplicate logical debit, conservative unknown liability, cost evidence and hard quota race proof. OIC-7 requires immutable release/evidence graph, sandbox and holdout isolation, valid oracle, calibrated judges, comparable cohort and uncertainty, no fake DNA and no weak promotion. OIC-8 requires source/negative evidence, bounded budget, dataset firewall, OIC-7 PASS, human approval, scoped canary, readback and rollback. OIC-9 requires measured SLOs, restore/integrity, tenant security, stress/chaos, runbooks and release signoff. Critical failure or missing evidence is NO-GO, never waived by a dashboard color.

**Reference fixtures:** deterministic local provider with scripted usage/timeout/duplicate receipt; price books spanning intervals/tiers/FX gaps; concurrent quota race; immutable coding repo with hidden tests, tool state oracle, RAG corpus, Arabic native cases, customer-service/sales simulator with policy violations, judge anchor cases and contaminated holdout markers. Fixtures live only in test/dev boundaries and never feed production Overview or accounting. Property tests cover ledger conservation, quota monotonicity under concurrency, price resolution uniqueness, candidate DAG acyclicity, scope isolation and comparison symmetry. No paid provider calls are required for foundational tests. Production data remains source-backed and separately authorized.
