## Required owner source and rights record

For each proposed case, supply or identify:

- first-party author or exact source/version and source checksum;
- permitted evaluation, derivative, and redistribution uses;
- case input and independently checkable oracle/rubric, stored separately when protected;
- deterministic environment and oracle revision, task type, target class, slices, limits, and expected state transitions;
- contamination, ambiguity, safety, and exposure review evidence;
- author and independent reviewer identities, timestamps, and digests.

If using first-party synthetic material, the rights record must be true: owner-authored internal fixture, commercial evaluation permitted, internal OIC derivative use permitted, and no third-party redistribution. A generated draft cannot assert those facts by default. Protected release review and publication must be performed by a distinct authorized publisher.

## Required families

- Coding / tool / schema: bounded task, pinned environment, public and evaluator-only checks, and prohibited side-effect assertions.
- Retrieval / memory: frozen corpus or memory state, evidence/citation labels, retrieval correctness, scope isolation, and prohibited-data non-recall checks.
- Multilingual / Arabic: native-authored and native-reviewed MSA understanding/generation, Egyptian Arabic understanding/generation, mixed Arabic-English, translation, localization, business communication, and sales/support dialogue slices. Each must record dialect/script, rubric, reviewer, and denominator. English translation alone is insufficient.
- Communication / sales: versioned simulator state and policy oracle; human calibration and adverse-policy checks are required before behavioral claims.

## Release gates

Each family is validated and released independently. Owner approval is required for every release; protected holdout publication also requires an independent publisher and isolated oracle/artifact checks. A registry count or successful compiler run alone does not establish domain validity or model quality. No paid provider dispatch is authorized by this handoff.

Do not place passwords, API keys, session tokens, protected answers, or credential values in this document or chat. Keep protected case inputs/oracles in the canonical artifact vault and reference them by approved identifiers/digests only.
