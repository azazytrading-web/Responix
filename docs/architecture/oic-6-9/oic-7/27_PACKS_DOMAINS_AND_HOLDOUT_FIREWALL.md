# OIC-7 final pack, environment and protected-data protocols

## Benchmark Pack plugin contract

A pack implements one versioned typed interface, never custom ledger/scoring semantics: `metadata(domain, taskTypes, targetClasses, license, securityTier, release)`, `caseManifest(dataset/case revisions, slices, hashes)`, `environmentRevision`, `reset(case, seed)`, `observe(state)`, `validateAction(actionSchema)`, `step(action, deadline)`, `termination(state, maxSteps)`, `verify(finalState, protectedOracleCapability)`, `measure(metric/judge revisions)`, `sampling/repetition/stopping policy`, `resourcePolicy(OIC6 budget, CPU/tool/network caps)`, `aggregate`, and `requiredSlices`. The core validates protocol version, rights, deterministic manifest digest, bounded steps and idempotent result envelope. Pack plugins run sandboxed with least privilege and cannot call promotion, edit evidence, expose protected answers or bypass OIC-6. A new Sales, Coding, Arabic, Terminal or Support pack adds a plugin/release, not a new scheduler or result store.

An external adapter pins external benchmark ID/version, source license/permission, upstream checksum, adapter code revision, mapping of cases/slices/metrics/target class, environment and evaluator differences, verification tier and comparability restrictions. `EXTERNAL_IMPORTED` data can be descriptive; only independently attested/OIC-executed evidence with a validated bridge can enter a decision gate. Adapter cannot substitute unknown external harness with current OIC harness. Revoked license invalidates new use and triggers governed retention/redaction, not silent deletion of historical result metadata.

## Protected holdout and exposure registry

Protected case input and answer are separate encrypted artifacts. Evaluator-only worker identity can decrypt oracle answer after target output is sealed; no API path sends it to candidate generation, OIC-8 proposal/learning memory, OIC Memory/Knowledge, ordinary runtime, browser, generic logs or trace metadata. Strict egress firewall denies those destinations; only score, bounded error category and uncertainty leave evaluator enclave. Access uses purpose-bound token, application/tenant ACL, audit and TTL. A pack author cannot approve their own promotion holdout release. Exposure registry stores source release/case hash, exposure channel, actor/time/scope, certainty (`CONFIRMED|SUSPECTED|POSSIBLE`), affected lineages and response. Unknown exposure is not proof of secrecy. Confirmed/suspected compromise quarantines decision use pending investigation; rotate release and invalidate affected verdicts without erasing history. Generated cases use quarantined draft tier until independent oracle/rights review and exposure scan.

## Domain execution precision

**Coding:** `BASE_MODEL` coding tests one bounded code-generation response; `AGENT_SYSTEM`/agentic coding tests an action loop in pinned repository commit, container image, dependency lock, tool/network policy, harness parser/planner/retry revision, evaluator code and hidden tests. These are different families. Hidden tests and oracle run outside writable sandbox; fixture/test tampering, stubs, network lookup or escaping sandbox produce policy failure/invalid environment as appropriate. Passing visible tests alone is not qualified success.

**Agent/terminal/tool:** `RESET→OBSERVE→ACT→STEP→TERMINATE→VERIFY` is the mandatory state/action protocol. Reset verifies environment digest. Observe returns permitted state only. Act validates typed tool and arguments against allowlist. Step commits simulator side effects under step ID; duplicate step returns same result. Terminate enforces success/timeout/step ceiling. Verify uses independent state oracle. Environment crash, timeout before valid observation or oracle failure yields `ENVIRONMENT_INVALID|NO_MEASUREMENT`, distinct from target error after a valid action. Tool metrics are separate: correct selection, argument schema, semantic correctness, multi-turn order, parallel-call consistency, rejection of irrelevant tools, hallucinated-tool rate, recovery, latency and target cost. A tool schema pass cannot imply correct side effects.

**Sales and support:** simulator holds protected customer/company need, budget, decision authority, timeline, objections, competitor state, product eligibility, price/discount boundaries, CRM state, deal state and tool permissions. Target sees only role-appropriate observations; action schema includes message, offer, tool/CRM action, handoff. Independent oracle checks product truth, discount authorization, customer fit and state transition. Report simulated outcome, process quality, customer fit, policy compliance and communication quality separately. An unauthorized discount, fabricated feature or pressure tactic is critical fail even if simulated deal closes. Support cases similarly pin issue, entitlement, knowledge truth, refund/escalation policy, tool state and verified resolution; helpful wording cannot compensate for wrong side effect. Multiple simulator/persona revisions and human calibration are required before promotion claims; simulator outcome is not real conversion truth.

**Arabic:** native-authored and reviewed slices include MSA understanding, MSA generation, Egyptian Arabic understanding, Egyptian Arabic generation, mixed Arabic/English, translation, localization, business communication and sales/support dialogue. Each slice pins dialect/script, cultural/policy rubric, native reviewer and denominator. Translated English cases are supplementary and cannot alone establish Arabic capability. Report within-slice results and uncertainty; cross-language normalization needs a bridge study.

**RAG:** isolate query generation, retrieval recall/precision against corpus revision, reranking, evidence selection, context assembly, answer correctness, citation validity and groundedness. A correct answer without permitted retrieval evidence does not prove RAG quality. **Memory:** test write eligibility, storage correctness, retrieval, relevance, freshness, conflict resolution, scope isolation and prohibited-data non-recall on versioned state. Stored salience/confidence never becomes measured utility. Tenant data requires consent and remains scope isolated.

**Temporal design:** interleave baseline/candidate cases in randomized blocks when provider drift risk exists; pin order/seed/time window. Adaptive sampling and early stopping are explicitly labeled with plan/method revision, selected-case probabilities and unexecuted counts; they never appear as full-suite execution. Benchmark quality report includes construct validity, ambiguity, difficulty/reference cohort, discrimination, ceiling/floor, oracle failure, judge agreement, contamination risk and known coverage limits. A pack release with unresolved critical oracle failure is not publication eligible.
