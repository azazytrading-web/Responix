## Adoption gates

No route switches to a control just because the primitive exists. The owning page records exact value unit/bounds, server field/endpoint, scope, lifecycle consequence, readback, error/stale behavior, keyboard and EN/AR+RTL acceptance. If source or semantics are absent, the control is explicitly unsupported or unmeasured. High-risk mutations use the [command contract](30_OIC_COMMAND_AND_ACTION_SYSTEM.md); all drafts and conflicts use [32](32_OIC_REACTIVE_CONFIGURATION_SYSTEM.md). The current BFF must be extended through an explicit fixed allowlist change in a later authorized implementation packet; no arbitrary URL pass-through.

## X1.3B bounded build sequence

X1.3B is **one** milestone with reviewed internal stages and no architecture invention:

1. **Foundation/tokens:** freeze type/style tokens, density and semantic CSS custom properties; confirm dependency/version/security decision.
2. **Primitive behavior layer:** adopt React Aria Components for supported interaction primitives; wrap them with OIC-owned typed APIs; establish focus, direction and validation contracts.
3. **Controls:** scalar/precision/range/number/choice/toggle, then domain composites (threshold, mixer and budgets only with explicit schemas).
4. **Commands:** consequence variants, disabled reasons, confirmation/arm, pending/result/recovery.
5. **Selection:** searchable scoped combobox/select, entity adapters, dependent relationship and async/error behavior.
6. **Workspace surfaces:** inspector, drawer, comparison, wizard, validation and persistent result composition.
7. **Reactive state components:** shared draft/diff/preset/constraint/apply/verify/conflict states; no generic API behavior assumptions.
8. **Composite patterns:** profile rack, provider setup, binding selector, permission matrix, threshold/budget, diff, apply/verify and conflict panel.
9. **Gallery:** `/dev/interface-system`, development-only fixtures, full state/scenario matrix and no production/API writes.
10. **Accessibility gate:** names, keyboard, focus, non-color states, zoom/reflow, reduced motion, contrast and assistive-technology spot checks.
11. **Localization gate:** native Arabic strings, locale formatting, EN/AR × LTR/RTL geometry and numerical semantics.
12. **Visual acceptance:** all four viewport/locale cells at normal/reduced motion; automated capture if configured plus owner review; honest evidence log.
13. **Serial validation/build:** focused tests, Console typecheck/lint/all configured tests/build, production route 404, diff/secret/boundary scans.
14. **Diff review and commit:** ensure artifacts/secrets excluded; commit OIC-only, push normally to `origin/oic`, verify remote ref/worktree and stop for review.

Each stage must keep Console :3002 and API :4100 live in separate persistent processes and produce tests/evidence before the next stage. Component groupings and acceptance layers are defined in [29](29_OIC_CONTROL_LIBRARY_CONTRACT.md), [35](35_OIC_INTERFACE_GALLERY_SPEC.md), [36](36_OIC_INTERFACE_ACCEPTANCE_GOVERNANCE.md) and [37](37_OIC_INTERFACE_EXTRACTION_STRATEGY.md).
